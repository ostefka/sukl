💊 SÚKL Léčiva

Agent pro M365 Copilot, který vyhledává léčivé přípravky a lékárny z otevřených dat Státního ústavu pro kontrolu léčiv. Odpovídá česky, data čerpá výhradně z API (nic si nevymýšlí).

Co agent umí

  • Vyhledat léky podle názvu, účinné látky, ATC kódu nebo držitele registrace
  • Filtrovat léky podle způsobu výdeje (volně prodejné / na předpis)
  • Filtrovat léky podle dostupnosti dodávek na trhu
  • Filtrovat léky podle lékové formy (tableta, sirup, mast…)
  • Zobrazit kompletní registrační detail léku (složení, ATC, SPC/PIL dokumenty)
  • Vyhledat lékárny podle města, PSČ nebo jména
  • Filtrovat pohotovostní, zásilkové a nemocniční lékárny
  • Zobrazit detail lékárny (adresa, kontakt, pracovní doba, vedoucí lékárník)
  • Kombinovat filtry — „volně prodejné léky s ibuprofenem ve formě tablety s dodávkami"

Co agent neumí / omezení

  • Zjistit, která lékárna má konkrétní lék skladem (data neobsahují zásoby)
  • Zjistit ceny léků nebo výši úhrad pojišťovnami
  • Doporučit dávkování, léčbu nebo upozornit na interakce
  • Vyhledat léky podle diagnózy nebo příznaků
  • Propojit léky a lékárny (dva oddělené datasety)
  • Odpovídat na dotazy mimo české léky a lékárny

Známé problémy a omezení

Léky a lékárny jsou oddělené

Data SÚKL neobsahují informace o tom, které lékárny mají které léky. Pokud potřebujete obojí, zeptejte se dvěma dotazy zvlášť.

Registrační data, ne klinická

Agent vrací administrativní registrační údaje — ne dávkování, interakce ani doporučení léčby. Pro tyto informace se obraťte na lékaře nebo lékárníka.

Dodávky = registrační stav

Příznak „dodávky: ano" znamená, že výrobce aktuálně dodává lék na český trh. Neznamená to, že je fyzicky dostupný ve vaší lékárně.

❓ Často kladené otázky

Odpovědi na časté dotazy ohledně agenta SÚKL Léčiva.

Kde agenta najdu v M365 Copilotu?

Agent je dostupný výhradně v prostředí M365 Copilot. Najdete ho v levém panelu Copilotu, nebo ho zavolejte přes ikonu @ — začněte psát @SÚKL Léčiva.

Agent neodpovídá / vrací chybu

Možné příčiny:

  • Backend se probouzí — po delší neaktivitě může proxy potřebovat pár sekund na start.
  • Dočasný výpadek — Azure služby mohou být krátkodobě nedostupné.

Zkuste dotaz zopakovat za minutu. Pokud problém přetrvává, kontaktujte správce.

Agent si vymýšlí data

Agent je nastavený tak, aby nepoužíval vlastní znalosti a čerpal pouze z API SÚKL. Pokud si přesto vymýšlí:

  • Ověřte, že jste agenta zavolali přes @SÚKL Léčiva (ne obecný Copilot)
  • Zkuste dotaz přeformulovat
Co je ATC kód?

ATC (Anatomicko-terapeuticko-chemický) klasifikační systém třídí léky do skupin. Například:

  • N02BE01 — paracetamol (N = nervový systém, 02 = analgetika)
  • M01AE01 — ibuprofen (M = muskuloskeletální systém)

Můžete hledat podle celého kódu i prefixu: „N02BE" najde celou skupinu.

Proč agent neví, kde lék koupím?

Data SÚKL obsahují registrace léků a registrace lékáren jako dva oddělené datasety. SÚKL nespravuje informace o tom, které lékárny mají které léky skladem.

Pro informace o dostupnosti kontaktujte lékárnu přímo.

Co znamená „dodávky: ano/ne"?

Dodávky = ano znamená, že výrobce/distributor aktuálně dodává lék na český trh. Dodávky = ne znamená, že lék je registrovaný, ale aktuálně se nedodává.

Mohu výsledky použít pro rozhodování o léčbě?

Ne. Agent poskytuje registrační údaje z databáze SÚKL. Pro rozhodování o léčbě, dávkování nebo interakcích se obraťte na svého lékaře nebo lékárníka.
