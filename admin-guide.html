Než začnete

Pro nasazení agenta do M365 Copilot potřebujete:

  • Roli Global Administrator, Teams Administrator nebo AI Administrator v Microsoft 365 tenantovi
  • ZIP balíček agenta — stáhněte níže

Backend infrastruktura (proxy, AI Search) je již provozovaná a nevyžaduje žádnou akci ze strany administrátora.

Stáhnout SUKLLeciva.zip

Postup nasazení — krok za krokem

1
Otevřete M365 Admin Center a přejděte do sekce Agents

Přejděte na admin.microsoft.com → Agents → All agents → klikněte Upload custom agent.

Nebo přejděte přímo na Agents → All agents.

2
Vyberte ZIP soubor

V dialogu nahrajte stažený soubor SUKLLeciva.zip.

3
Potvrďte a pokračujte

Systém validuje balíček. Pokud je vše v pořádku, klikněte Next.

4
Přiřaďte uživatele

Vyberte, kdo bude mít k agentovi přístup:

  • Entire organization — všichni uživatelé v tenantovi
  • Specific users/groups — konkrétní uživatelé nebo skupiny
5
Odsouhlaste oprávnění

Zkontrolujte požadovaná oprávnění agenta a klikněte Next.

Agent nepřistupuje k interním datům. Komunikuje pouze se svým proxy API na Azure — nepotřebuje přístup k souborům, e-mailům ani dalším firemním zdrojům.
6
Dokončete nasazení

Zkontrolujte souhrn a klikněte Finish deployment.

7
Hotovo!

Agent je nasazen. Propagace do M365 Copilot může trvat několik minut až hodin.

Uživatelé najdou agenta v levém panelu M365 Copilot nebo ho mohou zavolat přes @SÚKL Léčiva v chatu.

Aktualizace agenta

Při budoucích aktualizacích (nové funkce, opravy, změna instrukcí):

  1. Stáhněte nový ZIP balíček
  2. V M365 Admin Center přejděte na Agents → All agents
  3. Najděte SÚKL Léčiva v seznamu
  4. Klikněte na aplikaci → Update → nahrajte nový ZIP
Poznámka: Aktualizace ZIP balíčku je potřeba pouze při změnách na straně agenta (instrukce, pluginy, ikony). Pokud se mění pouze backend (proxy API, data v indexech), žádná akce ze strany administrátora není nutná.

Odebrání agenta

Pokud potřebujete agenta odebrat:

  1. V M365 Admin Center přejděte na Agents → All agents
  2. Najděte SÚKL Léčiva
  3. Klikněte Remove

Aktualizace dat

Data v indexech pocházejí z otevřených dat SÚKL. Pro aktualizaci je třeba znovu spustit import pipeline (Python skripty pro ingest).

Nasazení nové verze proxy

Nová verze proxy se nasadí pomocí skriptu deploy.ps1:

  1. Upravte kód v sukl-api/
  2. Změňte parametr $ImageTag v deploy.ps1 (např. v1.2.0)
  3. Spusťte .\deploy.ps1 — skript sestaví image, pushne do ACR a aktualizuje Container App
