Nasazení agenta SÚKL Léčiva do M365 Copilot

M365 Admin Center Copilot Agent Azure Container Apps
← Zpět na přehled agentů

Než začnete

K nasazení agenta budete potřebovat:

  • M365 Admin přístup — musíte mít oprávnění nahrávat vlastní aplikace a agenty do Teams Admin Centre
  • M365 Copilot licenci — agent funguje pouze s aktivní licencí Microsoft 365 Copilot
  • Balíček agenta — ZIP soubor s manifestem, pluginem a instrukcemi (ke stažení níže)
Stáhnout SUKLLeciva.zip

Postup nasazení

1

Otevřete Teams Admin Centre

Přejděte na admin.teams.microsoft.com a přihlaste se účtem s oprávněním pro správu aplikací.

2

Přejděte do správy aplikací

V levém menu vyberte Teams apps → Manage apps.

3

Nahrajte novou aplikaci

Klikněte na Upload new app (tlačítko v horní části stránky). Vyberte stažený soubor SUKLLeciva.zip a potvrďte nahrání.

4

Zkontrolujte detail aplikace

Po nahrání se zobrazí detail agenta. Zkontrolujte, že název je SÚKL Léčiva a typ je Declarative Agent (Copilot Agent).

5

Nastavte dostupnost

V sekci Users and groups nastavte, pro koho bude agent dostupný — lze přiřadit konkrétní uživatele, skupiny, nebo celou organizaci.

6

Publikujte aplikaci

Klikněte na Publish. Změna stavu na Published může trvat několik minut.

7

Ověřte funkčnost

Otevřete M365 Copilot pod uživatelem, který má přiřazenou Copilot licenci. V levém panelu by se měl zobrazit agent SÚKL Léčiva. Zkuste zadat: „Najdi léky s paracetamolem".

Aktualizace agenta

Pokud potřebujete aktualizovat agenta (nová verze balíčku):

  1. Stáhněte aktualizovaný ZIP balíček
  2. V Teams Admin Centre přejděte na Manage apps
  3. Najděte aplikaci SÚKL Léčiva a otevřete její detail
  4. Klikněte na Upload new version a nahrajte nový ZIP

Odebrání agenta

Pokud chcete agenta odebrat:

  1. V Teams Admin Centre přejděte na Manage apps
  2. Najděte aplikaci SÚKL Léčiva
  3. Klikněte na Actions → Delete a potvrďte smazání

Řešení problémů

ProblémMožná příčinaŘešení
Agent se nezobrazuje v Copilot panelu Propagace může trvat až 24 hodin Počkejte a obnovte stránku. Ověřte, že uživatel má přiřazenou Copilot licenci a je v cílové skupině.
Agent vrací chybu nebo neodpovídá Backend API může být dočasně nedostupné Zkuste dotaz za minutu. Pokud problém trvá, zkontrolujte stav Azure Container Apps v Azure Portal.
Nahrání ZIP selhává Neplatný formát nebo chybějící soubory Ověřte, že ZIP obsahuje manifest.json, ai-plugin.json, declarativeAgent.json a instruction.txt. Nerozbalujte a nezabalujte znovu — použijte originální ZIP.
Backend agenta běží jako Azure Container App — kontejnerizovaná Node.js aplikace s připojením na SÚKL OpenData API. SPC vyhledávání využívá Azure AI Search s vektorovými embeddingy. Správa backendu není součástí tohoto návodu.
